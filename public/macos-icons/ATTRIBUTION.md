Icons are synced into `public/images/` and `public/icons/` via:

```bash
node scripts/sync-mactahoe-icons.mjs --dark
```

The portfolio uses **dark UI chrome** plus MacTahoe **grey folder** and **user-trash-dark** place icons where available.
